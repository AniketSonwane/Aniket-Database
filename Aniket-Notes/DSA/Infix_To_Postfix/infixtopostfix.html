📚 Infix vs Postfix Expressions

Infix: Operators reside between operands (e.g. A + B). Familiar to humans, but requires parentheses and precedence rules to parse.

Postfix (RPN): Operators follow their operands (e.g. A B +). Computers evaluate postfix in a single linear pass using an evaluation stack without needing parentheses!

⚡ Precedence & Associativity

When an operator arrives, the stack pops any operator that has greater or equal precedence (>= priority), because that operator must be evaluated first in the postfix string!

  • ^: Priority 3 (Exponentiation)
  • * /: Priority 2 (Multiplication & Division)
  • + -: Priority 1 (Addition & Subtraction)
  • (: Priority 0 (Opening Parenthesis)

🛡️ The `bool operand` Validation

The boolean flag operand ensures that operands and operators alternate strictly:

  • operand == true: Just read an operand or ). Now expecting an operator or ).
  • operand == false: Just pushed an operator or (. Now expecting an operand.
  • Catches +A, A++B, AB, A(B+C), and A+B+!

⚡ Time & Space Complexity

Metric Complexity Reason
Time Complexity O(N) Each character scanned once; pushed & popped at most once.
Auxiliary Stack Space O(N) Stack stores operators and parentheses in worst case.
Output String Space O(N) Contains all operands and operators without parentheses.

💻 Complete C++ Implementation 

#include <iostream>
#include <stack>
#include <cctype>
using namespace std;

class InfixToPostfix {
public:
    int priority(char ch) {
        if (ch == '^') return 3;
        if (ch == '*' || ch == '/') return 2;
        if (ch == '+' || ch == '-') return 1;
        return 0;
    }

    bool isOperator(char ch) {
        return ch == '+' || ch == '-' ||
               ch == '*' || ch == '/' || ch == '^';
    }

    string convert(string infix) {
        stack<char> s;
        string postfix = "";
        bool operand = false;

        for (char ch : infix) {

            if (isalnum(ch)) {
                if (operand) return "Invalid Expression";

                postfix += ch;
                operand = true;
            }

            else if (ch == '(') {
                if (operand) return "Invalid Expression";

                s.push(ch);
                operand = false;
            }

            else if (ch == ')') {
                if (!operand) return "Invalid Expression";

                while (!s.empty() && s.top() != '(') {
                    postfix += s.top();
                    s.pop();
                }

                if (s.empty())
                    return "Invalid Expression";

                s.pop();
                operand = true;
            }

            else if (isOperator(ch)) {
                if (!operand) return "Invalid Expression";

                while (!s.empty() && s.top() != '(' &&
                       priority(s.top()) >= priority(ch)) {
                    postfix += s.top();
                    s.pop();
                }

                s.push(ch);
                operand = false;
            }

            else {
                return "Invalid Expression";
            }
        }

        if (!operand)
            return "Invalid Expression";

        while (!s.empty()) {
            if (s.top() == '(')
                return "Invalid Expression";

            postfix += s.top();
            s.pop();
        }

        return postfix;
    }
};

int main() {
    InfixToPostfix obj;

    string infix;

    cout << "Enter Infix: ";
    cin >> infix;

    cout << "Postfix: " << obj.convert(infix) << endl;

    return 0;
}
