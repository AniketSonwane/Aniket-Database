# Merge Sort

Merge Sort is an efficient, comparison-based, stable divide-and-conquer sorting algorithm. It divides the input array into two equal halves, recursively sorts each half, and then merges the two sorted halves back together into a single sorted array.

Divide & Conquer Visual Example:

Initial Array: [ 38, 27, 43, 3, 9, 82, 10 ]
Divide Phase 1: [ 38, 27, 43, 3 ] | [ 9, 82, 10 ]
Divide Phase 2: [ 38, 27 ] [ 43, 3 ] | [ 9, 82 ] [ 10 ]
Base Case: [ 38 ] [ 27 ] [ 43 ] [ 3 ] | [ 9 ] [ 82 ] [ 10 ]
Merge Step 1: [ 27, 38 ] [ 3, 43 ] | [ 9, 82 ] [ 10 ]
Merge Step 2: [ 3, 27, 38, 43 ] | [ 9, 10, 82 ]
Final Sorted: [ 3, 9, 10, 27, 38, 43, 82 ]

Divide and Conquer Strategy

1. Divide

Calculate mid = (low + high) / 2 to split the array into two smaller subarrays of equal or near-equal sizes.

2. Conquer

Recursively call mergeSort() on both the left and right halves until subarrays contain single elements (base case).

3. Combine

Invoke merge() to combine two sorted subarrays using single temp[100] array.

Merge Sort Step-by-Step Algorithm

1Start with the initial complete array indexed from low = 0 to high = n - 1.
2Check base case: if low >= high, return (subarrays of size 1 are sorted).
3Find middle index mid = (low + high) / 2.
4Recursively apply mergeSort(arr, low, mid) to sort the left half.
5Recursively apply mergeSort(arr, mid + 1, high) to sort the right half.
6Merge the two sorted halves using merge(arr, low, mid, high) into temp[].
7Copy elements back from temp[] to arr[].

Complexity Analysis

Time Complexity:

Case Complexity Reason
Best Case O(n log n) Consistently divides the array into halves log₂(n) times and performs n comparisons per level.
Average Case O(n log n) Takes O(n log n) time regardless of initial element ordering.
Worst Case O(n log n) Guaranteed O(n log n) time even for reverse sorted arrays.

Space Complexity:

O(n) Auxiliary Space

Merge Sort is not an in-place algorithm because temporary array temp[100] is allocated during merging to store intermediate sorted elements.

Algorithm Properties & Trade-offs

Divide & Conquer

Recursive Structure
Splits problem into smaller independent subproblems and combines solutions.

Time Complexity

O(n log n) Guaranteed
Highly predictable execution performance under all initial array conditions.

Stability

Stable Sort (Yes)
Preserves the relative order of duplicate elements during comparison.

In-Place

Not In-Place (No)
Requires O(n) auxiliary memory for temp[] array.

Advantages

  • Guaranteed O(n log n) time complexity.
  • Stable sorting algorithm.
  • Ideal for sorting linked lists & external files.

Disadvantages

  • Requires O(n) extra memory space.
  • Recursive stack adds overhead for small arrays.
