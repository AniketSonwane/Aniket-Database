# Bubble Sort

Bubble Sort is a simple comparison-based sorting algorithm. It repeatedly steps through the input list, compares adjacent elements, and swaps them if they are in the wrong order. This process is repeated until no swaps are needed, which indicates that the list is fully sorted.

Simple Trace Example:

Initial Array: [ 5, 1, 4, 2, 8 ]
Pass 1: Compare (5, 1) → 5 > 1 → Swap → [ 1, 5, 4, 2, 8 ]
Pass 1: Compare (5, 4) → 5 > 4 → Swap → [ 1, 4, 5, 2, 8 ]
Pass 1: Compare (5, 2) → 5 > 2 → Swap → [ 1, 4, 2, 5, 8 ]
Pass 1: Compare (5, 8) → 5 < 8 → No Swap → [ 1, 4, 2, 5, 8 ] (8 is placed in final position)

Notice how after Pass 1, the largest unsorted element (8) "bubbles up" to its correct position at the end of the array.

Bubble Sort Step-by-Step Algorithm

1Start with the first element at index j = 0.
2Compare adjacent elements: arr[j] and arr[j + 1].
3If arr[j] > arr[j + 1], swap them.
4Move to the next adjacent pair (j++).
5Continue until reaching the end of the unsorted portion (j < n - i - 1).
6The largest unsorted element is now locked in its correct final position at the end.
7Increment pass counter (i++) and repeat for remaining unsorted elements.
8Stop when i = n - 1 or no swaps occur during a pass.

Complexity Analysis

Time Complexity:

Case Complexity Reason
Best Case O(n) When array is already sorted (requires only 1 pass with optimized flag).
Average Case O(n²) On average, requires n(n-1)/2 comparisons and swaps.
Worst Case O(n²) When array is reverse sorted (requires maximum comparisons & swaps).

Space Complexity:

O(1) Auxiliary Space

Bubble Sort is an in-place sorting algorithm because it reorganizes the elements within the original array without allocating additional auxiliary array memory.

Theory & Properties

Stable Sorting Algorithm

Bubble Sort is stable. Equal elements retain their original relative order because swapping only occurs when arr[j] > arr[j+1] (strictly greater).

In-Place Sorting

Sorting is done entirely in place using a single temporary variable for swapping, yielding O(1) extra space.

Advantages

  • Extremely simple to understand and implement.
  • Requires no additional memory space (O(1)).
  • Detects if array is already sorted in O(n) time.

Disadvantages

  • O(n²) time complexity makes it very slow for large datasets.
  • Performs excessive element swaps compared to Insertion Sort.

Real-World Applications

While rarely used for large production datasets, Bubble Sort is widely used in computer science education to introduce sorting logic, loop invariants, algorithm complexity, and graphics programming (such as hardware polygon sorting).
