# Linear Search

Linear Search (also known as sequential search) is a simple searching algorithm that inspects each element of an array one by one from left to right until the target value is found or the entire array has been searched.

Linear Search Example:

Array: [ 10, 25, 30, 45, 50 ], Target = 45
i = 0: arr[0] = 10 == 45 → FALSE
i = 1: arr[1] = 25 == 45 → FALSE
i = 2: arr[2] = 30 == 45 → FALSE
i = 3: arr[3] = 45 == 45 → TRUE (Match Found!)
Result: Target 45 found at index 3
Note on Duplicate Values: If the array contains duplicate occurrences of the target value (e.g. [10, 20, 30, 20, 40] with target 20), Linear Search returns the index of the first occurrence (index 1) and stops.

Linear Search Step-by-Step Algorithm

1Start from the first element of the array (set i = 0).
2Check if i < n. If false, array traversal is complete.
3Compare the current element arr[i] with the target value.
4If arr[i] == target, return index i (Search successful!).
5If arr[i] != target, increment i (move to the next index).
6Repeat steps 2 to 5 until the target is found or index i reaches n.
7If the target is not found after checking all elements, return -1.

Complexity Analysis

Time Complexity:

Case Complexity Reason
Best Case O(1) The target element is found at the very first index (arr[0]).
Average Case O(n) On average, approximately half of the elements (n/2) are inspected.
Worst Case O(n) The target is at the last position or does not exist in the array.

Space Complexity:

O(1) Auxiliary Space

Linear Search requires no extra memory arrays or call stack memory.

Algorithm Properties & Trade-offs

Method

Sequential Traversal
Scans elements one by one from left to right.

Array Requirement

Works on Unsorted Arrays
No sorting required prior to searching.

Comparison-Based

Yes
Compares array values using equality operator ==.

Advantages

  • Very simple and easy to implement.
  • Works on unsorted and sorted arrays alike.
  • Requires O(1) space.
  • Handles duplicate values easily.

Disadvantages

  • Slow O(n) execution for large datasets.
  • In-efficient compared to Binary Search O(log n) on sorted data.

Space Complexity

O(1) Constant Space
Only uses index counter variable i.

Linear Search vs Binary Search

Feature Linear Search Binary Search
Array Requirement Any Array (Sorted / Unsorted) Sorted Array Only
Best Case O(1) O(1)

Worst Case O(n) O(log n)
