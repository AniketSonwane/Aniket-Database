📚 What is Circular Queue?

A Circular Queue is an advanced linear data structure that adheres to the FIFO (First In, First Out) principle.

The last position of the array connects directly back to the first position using modulo arithmetic (% 5), forming a continuous ring.

  • FRONT: Points to the first element to be deleted (initially -1).
  • REAR: Points to the last element inserted (initially -1).
  • WRAP: When rear reaches index 4, next is (4 + 1) % 5 = 0.

💡 Why Circular Queue?

In a simple Linear Queue, dequeuing elements creates empty spaces at the beginning of the array that can never be reused once rear == 4!

Linear:  [ Empty ][ Empty ][ 30 ][ 40 ][ 50 ] ➔ OVERFLOW!
Circular: [ 60 ][ 70 ][ 30 ][ 40 ][ 50 ] ➔ REUSED!

✨ Benefit: Zero wasted memory slots. New elements wrap around into previously freed positions without costly array shifting.

🔄 Modulo Arithmetic (% 5) Formula

Circular movement is governed by constant-time modulo division:

Next Rear:  rear = (rear + 1) % 5;
Next Front: front = (front + 1) % 5;
Full Test:  (rear + 1) % 5 == front
Empty Test: front == -1

When index is 4: (4 + 1) % 5 = 0 (Wraps seamlessly to start).

💻 Complete C++ Implementation 

#include <iostream>
using namespace std;

class CircularQueue {
    int arr[5];
    int front, rear;

public:
    CircularQueue() {
        front = -1;
        rear = -1;
    }

    void enqueue(int value) {
        if ((rear + 1) % 5 == front) {
            cout << "Queue is Full\n";
            return;
        }

        if (front == -1)
            front = 0;

        rear = (rear + 1) % 5;
        arr[rear] = value;
    }

    void dequeue() {
        if (front == -1) {
            cout << "Queue is Empty\n";
            return;
        }

        cout << "Deleted: " << arr[front] << endl;

        if (front == rear) {
            front = rear = -1;
        } else {
            front = (front + 1) % 5;
        }
    }

    void display() {
        if (front == -1) {
            cout << "Queue is Empty\n";
            return;
        }

        int i = front;

        while (true) {
            cout << arr[i] << " ";

            if (i == rear)
                break;

            i = (i + 1) % 5;
        }

        cout << endl;
    }
};

int main() {
    CircularQueue q;

    q.enqueue(10);
    q.enqueue(20);
    q.enqueue(30);
    q.enqueue(40);
    q.enqueue(50);

    q.display();

    q.dequeue();
    q.dequeue();

    q.enqueue(60);
    q.enqueue(70);

    q.display();

    return 0;
}
