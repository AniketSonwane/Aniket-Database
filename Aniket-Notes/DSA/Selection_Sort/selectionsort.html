# Selection Sort

Selection Sort repeatedly searches the unsorted portion of an array to find the smallest element. It then swaps that minimum element with the first element of the unsorted portion, gradually expanding the sorted prefix.

Simple Trace Example:

Initial Array: [ 64, 25, 12, 22, 11 ]
Pass 1: Find minimum in unsorted [64, 25, 12, 22, 11] → Min = 11 at index 4 → Swap 64 and 11 → [ 11 | 25, 12, 22, 64 ]
Pass 2: Find minimum in unsorted [25, 12, 22, 64] → Min = 12 at index 2 → Swap 25 and 12 → [ 11, 12 | 25, 22, 64 ]
Pass 3: Find minimum in unsorted [25, 22, 64] → Min = 22 at index 3 → Swap 25 and 22 → [ 11, 12, 22 | 25, 64 ]
Pass 4: Find minimum in unsorted [25, 64] → Min = 25 at index 3 → Swap 25 with itself → [ 11, 12, 22, 25, 64 ]

Selection Sort Step-by-Step Algorithm

1Start from index i = 0.
2Assume the current element is the minimum and set minIndex = i.
3Search the remaining unsorted elements starting from j = i + 1 up to n - 1.
4Compare arr[j] with arr[minIndex].
5If arr[j] < arr[minIndex], update minIndex = j.
6After scanning the entire unsorted portion, swap arr[i] with arr[minIndex] using temporary variable temp.
7Move i to the next position (i++).
8Repeat until the complete array is sorted (i = n - 1).

Complexity Analysis

Time Complexity:

Case Complexity Reason
Best Case O(n²) Even when the array is already sorted, Selection Sort still scans all remaining unsorted elements in two nested loops.
Average Case O(n²) Requires n(n-1)/2 comparisons regardless of initial element ordering.
Worst Case O(n²) Requires n(n-1)/2 comparisons for reverse sorted arrays.

Space Complexity:

O(1) Auxiliary Space

Selection Sort is an in-place sorting algorithm because it reorganizes elements within the array without allocating additional auxiliary array memory.

Algorithm Properties

In-Place

O(1) Extra Space
Uses only a few scalar variables (i, j, minIndex, temp).

Time Complexity

O(n²) Comparisons
Performs exactly n(n-1)/2 comparisons in all cases.

Stability

Usually Unstable
Long-distance swaps can alter the relative order of duplicate elements.

Adaptive

Non-Adaptive
Takes O(n²) time regardless of whether the array is partially or fully sorted.

Advantages

  • Extremely easy to implement.
  • Performs maximum O(n) swaps (useful when memory writes are costly).
  • Requires O(1) auxiliary space.

Disadvantages

  • O(n²) time complexity makes it slow for large datasets.
  • Does not adapt to pre-sorted data.
