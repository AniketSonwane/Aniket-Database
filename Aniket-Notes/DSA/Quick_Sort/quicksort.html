# Quick Sort

Quick Sort is an efficient, comparison-based divide-and-conquer sorting algorithm. It selects an element as a pivot (in this implementation, the last element arr[high]) and partitions the array around the pivot so that elements smaller than the pivot are placed to its left, and elements greater are placed to its right.

Partitioning Example:

Initial Array: [ 10, 7, 8, 9, 1, 5 ]
Selected Pivot = 5 (at high index 5)
Partitioning: Compares each element with pivot 5...
Elements < 5 move left: [ 1 ]
Pivot placed into final position: [ 1 ] [ 5 ] [ 8, 9, 10, 7 ]
Final Sorted: [ 1, 5, 7, 8, 9, 10 ]

Divide and Conquer Strategy

1. Divide

Select pivot = arr[high] and rearrange elements so that elements smaller than the pivot move left, and greater elements move right.

2. Conquer

Recursively call quickSort() on the left sub-array [low...pi-1] and right sub-array [pi+1...high].

3. Combine

Quick Sort is an in-place algorithm! No explicit combine or merge step is needed once sub-arrays are partitioned and sorted.

Quick Sort Step-by-Step Algorithm

1Select the last element as the pivot: pivot = arr[high].
2Set i = low - 1 to track boundary of elements smaller than pivot.
3Loop j from low to high - 1.
4Compare arr[j] with pivot.
5If arr[j] < pivot, increment i and swap(arr[i], arr[j]) using temporary variable.
6Continue until j reaches high - 1.
7Swap arr[i + 1] with arr[high] to place pivot into its correct final position.
8Return pivot index pi = i + 1.
9Recursively apply quickSort(arr, low, pi - 1) to the left partition.
10Recursively apply quickSort(arr, pi + 1, high) to the right partition.

Complexity Analysis

Time Complexity:

Case Complexity Reason
Best Case O(n log n) Occurs when partition repeatedly splits the array into two equal halves.
Average Case O(n log n) On average, random partition splits yield logarithmic recursion depth.
Worst Case O(n²) Occurs when pivot choice produces highly unbalanced partitions (e.g. already sorted array with last element pivot).

Space Complexity:

O(log n) Average Stack Space (O(n) Worst Stack Space)

Quick Sort is considered an in-place sorting algorithm because array element swapping requires O(1) auxiliary memory space.

Algorithm Properties & Trade-offs

Divide & Conquer

Partition-Based
Rearranges array relative to pivot before making recursive calls.

In-Place

In-Place (Yes)
Sorts elements directly inside array space without extra memory arrays.

Stability

Unstable (No)
Element swapping may alter relative order of duplicate elements.

Cache Friendliness

Excellent Cache Locality
Sequential array traversal yields exceptional real-world performance.

Advantages

  • Fast average O(n log n) execution time.
  • In-place memory efficiency.
  • Great cache line utilization.

Disadvantages

  • Worst-case time complexity is O(n²).
  • Not a stable sorting algorithm.
